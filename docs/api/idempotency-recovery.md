# 중단된 멱등성 요청의 종료

동일 사용자·키·본문으로 다시 요청할 때 QUEUED/ANALYZING의 생성 시각이
AI_REQUEST_TIMEOUT_MS + 60초보다 오래되면 조건부 UPDATE로 FAILED/ANALYSIS503을 기록한다.
다음 요청은 503을 재현한다. 새로운 분석에는 새 키가 필요하다.
기존 프로세스가 살아 있을 수 있으므로 같은 키로 AI를 재실행하거나 사용량을 환불하지 않는다.
원자적 상태 조건은 완료 결과와 최초 오류를 보존하며, 종료 후 늦은 성공은 저장 트랜잭션에서 거부한다.
정상 진행 중 요청은 계속 409를 반환한다. 만료된 키의 기존 409 규약은 유지한다.
