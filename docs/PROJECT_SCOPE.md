# 프로젝트 범위와 용어 정리

제안서 초안을 저장소 기준으로 정리한 문서입니다.

## 표기 정정

- GitHub Organization과 저장소는 `Dundeuni/Dundeuni-BE`로 표기합니다. 제안서의 `Deundeuni`, `deundeuni-server` 표기는 사용하지 않습니다.
- 현재 저장소의 역할은 백엔드이므로 서비스 전체 기능과 서버 책임을 구분해 작성합니다.
- Redis/BullMQ는 초기 MVP 필수 스택이 아닙니다. 영상 분석이나 장시간 AI 작업의 비동기 처리가 필요해질 때 검토합니다.

## 분석 결과 원칙

- `AI 생성·변조 가능성`과 `사기 위험`은 별도 값으로 반환합니다.
- 결과는 확정 판정이 아니라 위험 가능성, 판단 근거, 사용자가 취할 대응 방법을 제공합니다.
- 검사 원본은 기본 미보관을 원칙으로 하며, 기록 저장은 사용자 동의와 보관 기간을 정의한 뒤 제공합니다.

## 단계별 범위

| 단계 | 범위 |
| --- | --- |
| P0 | 인증·프로필, 이미지·텍스트·URL 검사, 결과·기록 조회, 위험 단계·근거·대응 가이드 |
| P1 | 전화번호·QR 검사, 가족 연결·공유, FCM 알림, 판별 퀴즈 |
| 확장 | 영상 분석, 통화·음성 분석, 자동 가족 알림, 신고 데이터 기반 개선 |
